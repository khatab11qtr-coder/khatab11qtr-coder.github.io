# طبعة 3D

موقع لتصميم مجسمات ثلاثية الأبعاد جاهزة للطباعة، ويعمل بالكامل داخل المتصفح (GitHub Pages).

## الميزات
- **ميداليات الأكواب**: كوب تيك أواي، كوب آيس بشفاطة، ومج ببخار. اكتب اسم الكوفي بالعربي أو الإنجليزي، ويطلع النص بارز أو محفور.
- **قوالب ميداليات عامة**: ميدالية اسم، دائرية، قلب، باركود QR (منيو/انستقرام)، وشعار من صورة.
- **من صورة إلى مجسم**: رفع عدة صور معاً وتحويلها إلى ليثوفين أو نقش بارز أو ميدالية أو قالب كوكيز، مع تحميل الكل بملف ZIP.
- **مجسم كامل بالذكاء الاصطناعي**: من 1 إلى 4 صور عبر Meshy API، ثم ضبط المقاس بالمليمتر وتصدير STL. يمكن أيضاً تحويل أي ملف GLB إلى STL.
- **الطباعة بلونين**: ملف للقاعدة وملف للنص، أو ارتفاع تغيير الفلامنت.
- **الطلب بالجملة**: قائمة أسماء تتحول إلى ميدالية لكل اسم في ZIP واحد.
- **حاسبة**: الوزن، ووقت الطباعة، وتكلفة الخامة، وسعر بيع مقترح.
- **أخرى**: حفظ التصاميم، وضع ليلي ونهاري، زر طلب عبر واتساب، ودليل طباعة.

ملفات STL مغلقة (watertight)، وحوافها ناعمة لأنها تُستخرج بطريقة Marching Squares مع earcut.

## الإعدادات
عدّل `js/config.js`: اسم المتجر، ورقم الواتساب، والعملة، وسعر الفلامنت.
